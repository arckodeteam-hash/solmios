⏱️ La línea del tiempo de versiones

V000hoy · sin nada → V001baseline (la foto) → V0021er cambio → V003otro cambio → V00…y así siempre

Cada versión es un script guardado en git. Nunca se edita uno viejo: siempre se suma el siguiente. Así la historia de la base queda completa, como la del código.
