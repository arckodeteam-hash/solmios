02Qué se está verificando

ComponenteQué significa el check
APIEl corazón de la plataforma responde: panel web, app móvil e integraciones hablan con ella. Si está en verde, el sistema operativo normal.
Base de datosEl propio API revisa su conexión a la base (checks.db en el endpoint de salud). En verde: reservas, facturas y sesiones se leen y escriben con normalidad.
App móvilUsa la misma API que se verifica arriba; su tienda de distribución (Google Play) es gestionada por Google. No tiene servicio propio que pueda caerse independiente.
Sitio webEstás viéndolo: si esta página carga, el sitio responde.

03Si algo está en rojo

  • Si solo tu hotel no entra y acá todo está verde, revisa tu conexión o escríbenos por el chat del panel — puede ser algo puntual de tu cuenta.
  • Si la API está en rojo o amarillo, ya lo sabemos: las alertas del sistema avisan al equipo técnico antes que a nadie. Puedes seguir el detalle por soporte@solmios.com.
  • Si el check no se puede ejecutar (navegador sin red, bloqueador), verás «no verificable» — eso no significa caído.
