02La app móvil en una frase

Es la misma plataforma, vestida para el personal que trabaja de pie: por rol, la camarera ve sus tareas, el supervisor su cola de revisión, mantenimiento sus tickets. Las preguntas comunes de la app están en el Centro de Ayuda.

03Integraciones y extensión

  • Canales (OTAs) vía el channel manager integrado.
  • Cerraduras TTLock y mensajería WhatsApp para huéspedes y equipo.
  • Pagos con tarjeta vía Stripe.
  • Tu propio software vía la API REST — misma API que usa el panel, autenticación por token, respuestas JSON uniformes.
